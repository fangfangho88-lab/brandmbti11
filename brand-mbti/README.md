# 品牌MBTI 1.0 网页MVP

纯静态 HTML/CSS/JavaScript，无依赖、无构建步骤、无外部字体或服务。打开 index.html 即可作答；建议部署后使用浏览器访问。

## 部署

- Netlify：解压后将 brand-mbti 文件夹拖入 Netlify 的手动部署入口。发布目录就是包含 index.html 的目录，无构建命令。
- Vercel：把文件夹内容上传到 Git 仓库，导入项目，选择 Other；不设置构建命令，输出目录为 `.`。
- GitHub Pages：将文件夹内文件放在仓库根目录，在 Settings → Pages 中选择从分支发布，选择对应分支及根目录。所有资源均使用相对路径，兼容仓库子路径。

## 文件和修改位置

- index.html：页面入口。
- style.css：响应式布局与打印样式。
- data.js：24题原文及选项；根据随附题库原文.md提取。
- app.js：六维映射、计分、报告、交互、本地存储与导出。
- 题库原文.md：用户提供的原始题库。

题目或规则实质变更时，同时更新 VERSION、存储 KEY、报告版本和题库版本。旧数据不应与新版本直接比较。报告为按定稿八部分结构生成的MVP文案，不构成模型验证。

## 使用及数据

逐题选择后点击下一题，可回退修改。未选择会阻止继续；无法判断属于有效作答状态，但不参与计分。每维至少两道有效量表题才计算均分；任一维不足两题时整体主导暂不判定。完整提交后显示六维量表条形图和独立情境次数图。并列最高分全部显示；伴随取其余维度次高分并保留并列。最高两维差值小于0.4标记混合倾向候选，最高分小于3.5则不明确。临时规则均未验证。

答案和已保存反馈仅存当前浏览器 localStorage；不自动上传，不跨设备同步。无后台收集服务。浏览器限制存储时页面提示；离开前应导出。反馈填写后需点击保存，再导出或复制JSON交给研究者。JSON包含版本、时间、原始答案、独立得分和反馈；未完成时也可导出备份。暂不支持数据导入。打印按钮可使用浏览器保存报告为PDF。
